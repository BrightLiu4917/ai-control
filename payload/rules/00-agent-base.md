# Agent 公共模板

本文件是新增或维护 `agents/agent-*.md` 时的公共基线。

## 标准章节

```md
# 中文角色名（agent-name）

## 角色名称

中文角色名

## 职责

## 适用场景

## 必须读取

## 工作流程

## 停止并询问

## 禁止事项

## 输出
```

## 公共规则

- 只保留本 agent 执行所需的核心规则，不把所有全局规则复制进来。
- 详细工程规则放在 `.ai/rules/`，由 `必须读取` 引用。
- 可执行、可重复、易错的动作优先固化为 `ai` 命令（new/check/test/ship），不靠人肉步骤。
- OpenSpec 相关操作只放 产品规格工程师（`agent-spec`）。
- 产品、业务建模与架构影响评估只放产品规格工程师（`agent-spec`）。

## 停止并询问基线

出现以下情况必须停止并询问：

- 输入信息缺失会影响正确性。
- 业务规则、字段、枚举、权限、租户、状态流转或 API 响应不清。
- 需要覆盖、删除、重命名或迁移已有产物。
- 需要引入新依赖或改变架构。
- 当前 agent 与其他 agent 职责冲突且无法按 `AGENTS.md` 的角色路由判定顺序。

## 输出基线

输出至少包含：

- 使用的中文角色和 agent id。
- 读取的事实源。
- 实施或审查结果。
- 变更文件，如有。
- 验证步骤。
- 假设和风险。
