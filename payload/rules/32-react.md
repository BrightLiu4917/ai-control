# React 技术栈规则

## 适用范围

适用于 React、Vite/Next.js、TypeScript、Ant Design 或其他管理端组件库项目。

## 接入原则

- 优先遵循目标项目已有目录、路由、状态管理、请求封装、权限组件和组件库。
- 禁止为单个页面引入新 UI 框架。
- API 字段、枚举、权限和状态必须来自 OpenSpec 或后端契约。
- 后端长整型 ID 在前端一律按字符串处理，禁止转 `Number`。

## 页面实现要求

- 组件拆分以真实复用和复杂度为准，禁止空壳抽象。
- 表格、筛选、分页、详情、弹窗和抽屉必须符合现有交互。
- 必须处理加载态、空态、错误态、权限态和提交中状态。
- 新增路由、菜单、按钮时必须确认访问控制模式、责任系统和权限点；如果本服务不建设 RBAC，按外部权限系统约定处理。
- 构建、类型检查、lint 或最小手动验证必须至少执行一种。
