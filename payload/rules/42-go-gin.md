# Go Gin 技术栈规则

## 适用范围

适用于 Go、Gin、MySQL、Redis、RESTful API 后端项目。

## 接入原则

- 优先遵循目标项目已有分层、错误码、响应体、日志、配置和中间件。
- 不清楚 ORM、事务、鉴权、权限、分页、错误码时必须先问。
- 不得把 Java/Spring Boot 的目录、注解或依赖规则套到 Go 项目。

## 实现要求

- Handler 只做入参、基础校验和响应，不堆业务规则。
- Service 承载业务动作、状态流、事务和权限判断。
- Repository/DAO 负责数据访问，SQL 必须显式字段。
- 涉及多表写入必须使用事务。
- API 对外 ID 按字符串处理，避免前端精度问题。
