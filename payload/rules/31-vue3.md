# Vue3 技术栈规则

## 适用范围

适用于 Vue3、Vite、TypeScript、Element Plus 或其他管理端组件库项目。

## 接入原则

- 优先遵循目标项目已有目录、路由、状态管理、请求封装、权限指令和组件库。
- 禁止为单个页面引入新 UI 框架。
- API 字段、枚举、权限和状态必须来自 OpenSpec 或后端契约。
- 后端长整型 ID 在前端一律按字符串处理，禁止转 `Number`。

## 页面实现要求

- 列表必须有加载态、空态、错误态和权限态。
- 表单必须有前端校验、后端错误展示和重复提交防护。
- 审核、删除、禁用等高风险操作必须有确认。
- 新增路由、菜单、按钮时必须确认访问控制模式、责任系统和权限点；如果本服务不建设 RBAC，按外部权限系统约定处理。
- 构建、类型检查、lint 或最小手动验证必须至少执行一种。
